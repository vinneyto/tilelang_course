# Broadcasting без магии: bias по строкам

PyTorch автоматически растягивает вектор `bias` формы `[N]` на матрицу
`X[M, N]`. В низкоуровневом ядре broadcasting превращается в явную формулу:
каждый элемент `Y[row, col]` читает `bias[col]`.

Это полезная связь между тензорной математикой и GPU-кодом: broadcasting не
создаёт физическую матрицу bias, а задаёт способ переиспользовать значения.

## Задание

Реализуйте fused-ядро `build_row_bias_relu(M, N, ...)`, вычисляющее
`Y = relu(X + bias)`. Используйте двумерную сетку из предыдущего задания и не
создавайте промежуточный буфер.

## Что здесь происходит

Новых механизмов запуска нет: упражнение закрепляет `T.Kernel`,
`T.Parallel`, двумерные индексы и `T.max`. Новая идея — один и тот же индекс
используется для чтения буферов разной размерности:

```text
X[row, col]  берёт элемент матрицы;
bias[col]    берёт одно значение для всего столбца;
Y[row, col]  получает сумму после ReLU.
```

Вектор `bias` не копируется `M` раз. Потоки разных строк читают одно и то же
значение `bias[col]`.

## Параллель с WebGPU

В WGSL `X`, `bias` и `Y` были бы тремя storage buffers. Для каждой global
invocation логика выглядела бы как `y[row, col] = max(x[row, col] +
bias[col], 0.0)`. PyTorch-запись `x + bias` скрывает выбор `bias[col]`, а
TileLang/WGSL-код делает его явным.

Fusion снова означает один dispatch вместо двух: промежуточная матрица
`X + bias` не записывается в global memory перед ReLU.

## Как решить по шагам

1. Скопируйте ментальную структуру предыдущего задания, но не готовое решение:
   сначала самостоятельно выпишите формы каждого буфера.
2. Объявите `X` и `Y` как `T.Tensor((M, N), "float32")`, а `bias` — как
   `T.Tensor((N,), "float32")`.
3. Создайте двумерную сетку: число блоков `x` покрывает `N`, число блоков `y`
   покрывает `M`.
4. В `T.Parallel(block_M, block_N)` вычислите `row` и `col` точно так же, как
   в `matrix_add_2d`.
5. Прежде чем писать код, подставьте конкретный элемент, например
   `Y[2, 5] = relu(X[2, 5] + bias[5])`. Это показывает, почему у bias нужен
   только `col`.
6. Перенесите эту формулу в kernel через `T.max(..., 0.0)` и сделайте одну
   запись в `Y[row, col]`.
7. Верните kernel и сравните результат с `torch.relu(x + bias)`.
